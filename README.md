# 動態歌詞字幕工具：功能手冊與 SRT 標記指南

> 給 AI 助手（Gemini）閱讀的規格書。目的：讀完後，能根據使用者提供的歌詞 SRT 與用途（例如 MAD 上字幕），為每一句選擇合適的版型、動畫與特效，輸出可直接匯入本工具的「帶標記 SRT」，並建議全域設定。
> 本文只列出**實際存在**的名稱。凡不在清單內的名稱一律不要使用（工具遇到未知版型會退回 `lowerleft`，未知進退場／特效可能無效）。

---

## 1. 工具是什麼

單檔網頁（`index.html`）＋離線渲染（`node render/run.mjs`）。把 SRT 歌詞轉成「動態文字」畫面：每一句有版型（排版與動畫風格）、進場、退場、持續特效、位置、樣式、副文。時間軸完全由 SRT 的時間碼決定。

輸出（離線渲染）：
- `preview.mp4`：背景＋文字（可合成音樂）。
- `text_alpha.mov`（`--alpha`）：只有文字的透明層，**給剪輯軟體疊在影片上，MAD 最常用**。
- `--layers`：同時輸出透明文字層 `text_alpha.mov` 與氛圍層 `ambient.mp4`（背景、粒子、暗角等，無文字）。
- `--chroma`：純色（預設 `#00ff00`）背景加文字，給不吃透明檔的剪輯軟體用色鍵摳掉。

---

## 2. SRT 標記語法（最重要）

標準 SRT 區塊：

```
序號
00:00:01,000 --> 00:00:03,700
標記＋歌詞文字
```

文字行完整格式（**順序固定，每一段皆可省略**）：

```
#版型+進場+退場~持續特效^位置@樣式1,樣式2 主文||副文
```

| 段落 | 符號 | 說明 | 範例 |
|---|---|---|---|
| 版型 | `#` | 排版與動畫風格，見第 3 節 | `#center` |
| 進場 | 第一個 `+` | 文字出現的動畫，見第 4 節 | `#center+rise` |
| 退場 | 第二個 `+` | 文字消失的動畫；只想指定退場時，進場要補上 `fade` | `#center+fade+blur-out` |
| 持續特效 | `~` | 句子停留期間持續的效果（只能一個），見第 5 節 | `~float` |
| 位置 | `^` | 九宮格定位，見第 7 節 | `^bc`、`^tl:5:-2` |
| 樣式 | `@` | 逐字樣式，可用逗號疊加，**最多 3 個**，見第 6 節 | `@neon,chromatic` |
| 主文 | — | 歌詞本文。`{關鍵字}` 用大括號標出要強調的字 | `我只想{擁抱}你` |
| 副文 | `\|\|` | 主文下方的極小裝飾行（拼音、英文、日期） | `\|\|SYNC COMPLETE` |

重要規則：
1. **整段標記中間不能有空白**（空白代表標記結束、主文開始）。
2. 標記與主文之間用**一個空白**分隔。
3. 沒有 `#` 標記的句子會自動選版型（有 `{}` 用 `split`，否則 `lowerleft`）。
4. 一個 SRT 區塊只放**一行**文字（標記＋主文＋副文）。
5. 不要改動時間碼與歌詞原文；只在句首加標記（與必要時加 `||副文`）。

完整範例：

```
12
00:00:31,000 --> 00:00:33,700
#center+zoomin+blur-out~shimmer^bc@outline,chromatic 我只想{擁抱}你||I JUST WANT TO HOLD YOU
```

## 3. 版型清單（`#`）

說明欄中，標「（文件）」者來自專案說明文件，描述可靠；標「（推定）」者依名稱與範例推定，使用前請以名稱字面意義為準，不要過度承諾細節。

### 基本版型
| 名稱 | 說明 |
|---|---|
| `lowerleft` | 左下角文字加一條裝飾線，最像一般歌詞字幕；無標記時的預設（文件） |
| `split` | 文字被 `{}` 切開，貼在畫面左右兩側，適合兩個字的強調（如 `{靠}{近}`）（範例） |
| `center` | 置中，最適合搭配樣式與進場動畫，**最安全、通用的選擇**（文件） |
| `bounce` | 跳動感排版，適合節奏明快的句子（推定） |
| `slam` | 大字由大縮小「砸」到畫面上，短促有力，適合短句重點（範例／程式） |
| `neon` | 霓虹感（推定） |
| `karaoke` | 逐字依句子時長變亮，適合跟唱（文件：與 `@karaoke` 類似概念） |
| `typewriter` | 打字機逐字出現（推定） |
| `vertical` | 直排文字（推定；沙箱未驗證外觀） |
| `blurfocus` | 由模糊慢慢對焦（範例） |
| `wipe` | 掃過式揭露（推定） |
| `glitch` | 訊號故障風（範例） |
| `stack` | 多行堆疊（推定） |
| `outline-big` | 大字空心（推定） |
| `subtitle-box` | 帶底色框的字幕（推定） |
| `poster` | 海報式大字，可搭配 `{}` 強調（範例） |
| `flash-words` | 以空白分隔的詞逐個快速閃現，例如 `快 跑 不 要 停下來`（範例） |
| `keyword` | 以 `{}` 標出的關鍵字被強調（範例） |
| `trail` | 拖影（推定） |
| `text-mask` | 文字遮罩效果（推定） |
| `longshadow` | 長影（推定） |
| `bubble` | 泡泡（推定） |
| `blinds` | 百葉窗（推定） |
| `hanko` | 日式印章風，偏直排（推定；沙箱未驗證外觀） |
| `collage` | 拼貼風（範例） |
| `handwrite` | 手寫（範例） |
| `marker` | 螢光筆標記，可搭配 `{}`（範例） |
| `scroll` | 捲動歌詞，前後兩句淡出顯示（程式） |
| `orbit` | 文字沿圓弧環繞（程式） |
| `diagonal` | 斜向大字（程式） |
| `circle-badge` | 圓形徽章（推定） |
| `split-screen` | 分割畫面（推定） |

### 較新的版型（文件說明可靠）
| 名稱 | 說明 |
|---|---|
| `ripple-pool` | 隨拍子擴散的水環 |
| `constellation` | 星點連線後聚成字 |
| `particle-form` | 粒子聚成字再散開 |
| `parallax-depth` | 多層景深視差 |
| `polaroid` | 相紙卡依序滑入疊放 |
| `page-flip` | 3D 翻頁露出下一句（會顯示前一句；單獨使用時前後空白） |
| `ink-bleed` | 墨點暈開揭露 |
| `laser-scan` | 亮線掃過露出文字（偶數句橫向、奇數句直向） |
| `split-flap` | 機場翻板 |
| `wave-path` | 文字沿波浪流動 |
| `mirror-reflect` | 水面倒影 |
| `cylinder` | 滾筒翻轉（會顯示前後句） |
| `iris-frame` | 光圈框（偶數句圓、奇數句矩形） |
| `annotate` | 手繪圈選、底線、星號標記 `{關鍵字}`（三種標記輪流） |

### 滿版版型（會忽略 `^位置`）
`hud-frame`（遊戲介面風）、`laser-scan`、`iris-frame`、`marquee`（跑馬燈）、`danmaku`（彈幕）、`border-run`（邊框跑動）、`zoom-tunnel`（穿越隧道）。這些本身就是整個畫面的效果，**不要替它們加 `^位置`**。

## 4. 進場與退場

**進場（第一個 `+`）**：`fade` `rise` `drop` `zoomin` `zoomout` `spin` `flip` `stagger` `mask-up` `elastic` `swing` `ripple` `scramble` `split-reveal` `iris`

**退場（第二個 `+`）**：`fade` `sink` `zoomout-fade` `blur-out` `slide-out` `dissolve` `shatter` `glitch-out`

用字提示（依名稱字面意義）：`fade` 柔和；`rise`／`drop` 由下／上進入；`zoomin`／`zoomout` 縮放；`elastic` 彈性；`scramble` 亂碼還原（適合科技、故障）；`stagger` 逐字錯開；`dissolve`／`shatter`／`glitch-out` 退場時溶解／碎裂／故障。

---

## 5. 持續特效（`~`，每句至多一個）

`float`（漂浮）`shake`（抖動）`flicker`（閃爍）`rainbow`（彩虹色）`wave`（波動）`shimmer`（流光掃過）`gradient-flow`（漸層流動）`chromatic`（色差抖動，隨 BPM）`outline-pulse`（輪廓光隨拍脈動）`highlight-word`（逐字依序亮起）`stopmotion`（定格動畫感）

---

## 6. 樣式（`@`，可逗號疊加，單句最多 3 個）

`neon` 霓虹、`glow-soft` 柔光、`outline` 空心、`chromatic` 色差、`gradient` 漸層、`longshadow` 長影、`trail` 拖影、`stamp` 蓋章、`glitch` 訊號閃爍、`karaoke` 逐字變亮。

限制：
- `karaoke` 與 `gradient` 同用時以 `karaoke` 為準。
- `stamp` 最適合單行置中的版型（如 `center`）。
- 水波折射等效果需要 WebGL2；不可用時改簡化版，不影響使用。
- **綠幕輸出（`--chroma`）會移除所有發光與陰影類樣式**（`neon`、`glow-soft`、`longshadow`、`chromatic` 等），需要綠幕時請少依賴它們。

---

## 7. 位置（`^`）

九宮格錨點：`tl tc tr`／`ml mc mr`／`bl bc br`（上／中／下 × 左／中／右）。

| 寫法 | 意思 |
|---|---|
| `^bc` | 下中 |
| `^tl:5:-2` | 左上，再右移 5%、上移 2%（% 為畫面寬／高；Y 為正向下） |
| `^:10:0` | 不指定錨點，只做微調（錨點跟隨全域設定） |
| `^auto` | 這句維持版型原位 |

沒寫 `^` 時，版型維持自己原本的位置。**MAD 用途的重點**：影片原本可能有人物臉部、原生字幕、LOGO；用 `^` 把歌詞移到安全區（常見：`^bc` 下中、`^tc` 上中），並避開畫面主角位置。設定位置的句子，副文會貼在主文正下方。

## 8. 全域設定（`config`，離線用 JSON；網頁面板亦可調）

只列確定存在的常用項目：

| 欄位 | 說明 |
|---|---|
| `bpm` | 節拍速度，影響脈動、色差、跳動等（預設 120） |
| `font` | 字體：`明體` `黑體` `圓體` `楷體` `等寬` `英文展示` |
| `weight`、`spacing` | 字重（100–900）、字距（em） |
| `color`、`accent` | 文字色、強調色（`#rrggbb`） |
| `speed`、`enter`、`exit` | 全域動畫速度、進場秒數、退場秒數 |
| `textScale` | 文字整體縮放 %（20–300） |
| `dim` | 背景遮罩暗度 0–90 |
| `bgMode`、`bgColor` | 背景：`gradient`／`solid`／`transparent`，及純色色碼 |
| `textShadow` | 文字柔和陰影（提升可讀性，**疊在影片上時建議開**） |
| `particles`、`pMode` | 粒子數；粒子樣式 `dots` `snow` `rain` `sakura` `stars` |
| `grain`、`vignette`、`scan` | 噪點、暗角、掃描線 |
| `trans` | 句間轉場：`cut` `flash` `crossfade` `wipe` `zoom` |
| `tone` | 整體色調濾鏡（CSS filter 字串，如 `grayscale(1)`） |
| `posAnchor`、`posX`、`posY`、`posSafe` | 全域文字位置（`tl…br`，空字串＝版型原位）、微調 %、安全邊界 % |
| `bokeh`、`leak`、`lightning`、`scratch`、`crt`、`vhs`、`invBar`、`kb` | 疊加特效開關（散景、漏光、閃電、刮痕、CRT、VHS、反白條、緩慢推近） |
| `lock` | 鎖定所有句子使用同一版型（如 `center`） |

內建預設組合（面板可一鍵套用）：`動畫PV`、`霓虹夜`、`簡約明體`、`強烈節奏`、`遊戲PV`、`復古VHS`、`櫻花日系`、`賽博龐克`、`極簡海報`、`電影字幕（底部置中）`、`街頭拼貼`。

## 9. 設計準則（給 AI 的選擇建議）

1. **先判讀意境**：依整首歌的情緒（抒情、熱血、陰鬱、復古、科技、搞笑）決定整體「色彩＋字體＋基底版型」，再逐句微調。
2. **大多數句子用安全選擇**：`center`、`lowerleft`，搭配簡單進場（`fade`、`rise`）與退場（`fade`）。**花俏版型留給高潮、關鍵詞、段落轉折**，約佔全部句子的 20–30%。
3. **看句長與時長**：句子很短（< 1.5 秒）別用慢動畫（`scramble`、`particle-form`、`constellation` 需要時間）；用 `slam`、`center+zoomin`、`flash-words`。
4. **看字數**：長句避免 `vertical`、`hanko`、`split-flap`、`orbit`、`diagonal` 這類對字數敏感的版型。
5. **節奏對齊**：快歌用 `bounce`、`slam`、`flash-words`、`~shake`、`trans: flash`；慢歌用 `blurfocus`、`ink-bleed`、`mirror-reflect`、`~float`。
6. **用 `{}` 抓關鍵詞**：只在 `split`、`keyword`、`marker`、`annotate`、`poster` 這類會處理關鍵字的版型使用，一句 1–2 個。
7. **相鄰句要有變化，但不要過度**：連續三句以上完全不同的版型會雜亂；同一段落（主歌／副歌）維持同一視覺語言，副歌再升級。
8. **可讀性優先**：長影、霓虹、色差疊在複雜影片上可能難讀；MAD 用途建議 `textShadow: true` 並降低花俏樣式比例。
9. **滿版版型**要節制（每首最多幾次），且不要加 `^`。
10. **`page-flip`、`cylinder`** 會顯示前後句，不要連續使用，也不要放在第一句或最後一句。

## 10. 用途導向：MAD 上字幕

- 產出多半是**疊在影片上的透明層**：離線輸出 `--alpha`（或 `--layers`），在剪輯軟體把 `text_alpha.mov` 放在影片上方軌道。
- 文字要避開角色臉部與原生字幕：大量使用 `^bc`／`^tc`，必要時 `^bc:0:-4` 之類微調。
- 配合畫面剪輯節奏：每句的 SRT 時間碼就是出現時間，**不要改時間碼**；若句子與畫面切點不合，請在報告中提出建議而不是自行改動。
- 角色／作品的情緒（熱血、悲壯、日常、搞笑、賽博）決定字體與特效強度；`textShadow` 建議開。
- 需要在剪輯軟體摳色時用 `--chroma`，此時避免依賴發光陰影類樣式。

## 11. 輸出格式要求（AI 回覆時請遵守）

1. **完整的帶標記 SRT**（放在一個程式碼區塊）：保留原序號、原時間碼、原歌詞文字；只加標記與（必要時）`||副文`。
2. **整體設計說明**（簡短）：整首歌的意境判讀、色彩／字體建議、各段落（前奏、主歌、副歌、橋段、尾奏）的視覺策略。
3. **建議的 `config` JSON**（只用第 8 節列出的欄位）。
4. **逐句理由表**（序號｜版型＋進退場＋特效｜一句話理由），句數很多時只列關鍵句與段落轉折。
5. 不確定名稱是否存在時，**使用第 3–6 節已列出的名稱**，不要自創。

## 12. 常見錯誤（請避免）

- 標記中間加空白：`#center + rise` ✗ → `#center+rise` ✓
- 順序顛倒：`@neon#center` ✗；固定順序為 `#版型+進場+退場~特效^位置@樣式`
- 同一句超過 3 個樣式、超過 1 個 `~` 特效
- 對滿版版型加 `^位置`
- 使用不存在的名稱（例如 `#fade`、`+bounce`、`~glow`）
- 把標記寫在句子中間，或把一句拆成多行
- 改動時間碼或歌詞原文
